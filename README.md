# Nexus Releases

Changelogs, downloads, and the public issue tracker for the
[Nexus]() desktop app.

> Nexus is closed-source software. This repository does not contain —
> and will not accept pull requests containing — application source
> code. It exists so users have a real place to report bugs, request
> features, and see what changed in each release.

## 📥 Download

Get the latest version at **[download]()**.

## 🐛 Found a bug? Have an idea?

Use the [Issues](https://github.com/getnexusapp/releases/issues) tab —
please use the Bug Report or Feature Request template so we have what we
need to act on it. See
[CONTRIBUTING.md](https://github.com/getnexusapp/.github/blob/main/CONTRIBUTING.md)
for what makes a good report.

## 💬 Questions & general discussion

Use [Discussions](https://github.com/getnexusapp/releases/discussions)
rather than Issues for anything that isn't a specific bug or feature
request.

## 🔒 Security issues

Please don't file these publicly — see
[SECURITY.md](https://github.com/getnexusapp/.github/blob/main/SECURITY.md).
